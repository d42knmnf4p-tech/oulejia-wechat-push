# 欧乐家 · 企业微信推送配置指南

> 目标：把"每周五主推 + 节假日当天加发"的话术，自动推送到你建的企微群里，销售长按复制转发给客户。
> 整个配置只需做一次。填好 Webhook 后，自动推送立即生效。

---

## 第一步：在企业微信里建群并加机器人

1. 打开**企业微信**（手机端或电脑端均可），建一个新群。
   - 把 **4 个销售**拉进来，你自己也进群（方便随时查看）。
   - 群名建议就叫：**欧乐家微信营销**（和 config.json 里的 group_name 一致）。
2. 进群后，点右上角 **「···」**（更多）。
3. 找到并点 **「群机器人」**。
4. 点 **「添加机器人」→「新创建一个机器人」**。
5. 机器人名称填：**欧乐家微信营销**，点创建。
6. 创建成功后会看到 **Webhook 地址**，点 **「复制」** 拿到完整链接。
   - 形如：`https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=693a91f6-xxxx-xxxx-xxxx-xxxxxxxxxxxx`

> ⚠️ 如果群里没有「群机器人」入口：
> 通常是企业管理员关闭了该能力，或群是外部客户群。
> 解决：联系你们企业微信管理员在「管理后台 → 客户联系/群管理」中开启群机器人；或换一个内部群（只拉员工）即可。

## 第四步：以后就全自动了

验证通过后，什么都不用管了。已建好的定时任务会**每天 09:30** 自动运行：
- 当天是**周五** → 推本周主推话术

- 当天无排期 → 静默跳过，不打扰

## 注意事项

- 🔒 **Webhook 就是密钥**：谁拿到都能往你群里发消息，不要发到群外或公开渠道。
- 📨 **群机器人只发群里，不会替你发给客户个人微信**——这是既定方案：话术推到群，销售长按复制、10:00 准点发客户。
- ⏱️ **频率限制**：单个群机器人每分钟最多 20 条，我们每周仅 1–2 条，完全够用。
- 🔄 **改文案**：改 `build/` 里的生成脚本 → 跑一次 `merge.py` → 日历、审阅稿、数据自动同步，推送内容跟着更新。

## 找不到群机器人 / 如何拿到真正的 Webhook

### 群机器人在哪开
群机器人只支持**内部群**（成员全是本企业员工），且需管理员在后台开启：
- 管理员登录 企业微信管理后台 https://work.weixin.qq.com
- 左侧「我的企业」→「聊天管理」→「群机器人」→ 勾选「允许成员在群中添加群机器人」
- 群里刷新后，右上角「···」→「群机器人」即出现

### 推送只认真正的 Webhook 地址
后台 `openBotProfile/...` 这类链接是**机器人配置页**，不是 Webhook。推送脚本要的是下面这条：
```
https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxxxxxx
```
两种取法任选其一：
- **方式A（客户端最快）**：企业微信客户端进群 → 右上角「···」→「群机器人」→ 点机器人名 → 复制 Webhook 地址
- **方式B（后台）**：⚠️ 企业微信管理后台通常**只显示机器人列表、不暴露 Webhook 密钥**，你在后台找不到 key 是正常的。仅当你那个配置页真有「Webhook 地址」一栏才从这里复制；否则一律走方式A（客户端群聊）。
